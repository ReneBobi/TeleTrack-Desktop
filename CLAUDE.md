## Crew notes

- **This repo is the live update feed** for the TeleTrack desktop client (a thin viewer). GitHub Releases here are what installed clients auto-download, so treat every release action as a production deploy.
- **Never publish, edit, delete or re-tag releases or their assets without explicit owner instruction.** Live clients consume them immediately.
- **No source code lives here.** The only tracked file is `README.md`, and the client is built elsewhere. Do not assume a language, framework, build, test or CI command, and do not invent any.
- **The update format is unknown.** Asset naming, update metadata (e.g. `latest.yml`) and the versioning scheme must be confirmed against the client's source before any release work. Ask the owner if it is unclear.
- **Keep the README accurate.** Describe only what is actually in the repo and mark unknowns as unknown. Slovenian-first or bilingual EN/SL wording fits the owner's style.
- **Commits:** use conventional prefixes (`docs:`, `chore:`, …) with short messages.
- **Never copy secrets or credentials** (e.g. signing keys, tokens) into the repo, the README or release notes.
